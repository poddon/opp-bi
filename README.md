# BI Дашборд · СК ОПП · Алабуга

Концепт BI-дашборда по техническому заданию на разработку по СК ОПП (2026).

**Сайт:** https://poddon.github.io/opp-bi/

## Возможности (по ТЗ)

### Главный экран
- Панель **План / факт отметок за период** с кольцевой диаграммой
- Выбор периода: День / Неделя / Две недели / Месяц / Год / Ввести дату (кастомный диапазон)
- При кастомной дате — скрываются План и Осталось
- KPI-блоки: Групп вычитано (кликабельно), Пар проведено, Отметки, Посещаемость
- График **Выполнение госплана** по двухнедельным периодам (скролл + tooltip)
- Таблица **Ближайшие занятия**

### Дополнительный экран
- Выбор направления (ЧПУ / Микро / Робототехника)
- Таблица групп с освоением, парами, статусом
- KPI выбранной группы
- Таблица студентов с отметками по модулям (✓ / —)
- Поиск по ФИО (работает по всем группам)

## Технологии
Чистый HTML + CSS + JS, без зависимостей. Тёмная тема, адаптив.
